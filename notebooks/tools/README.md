# Tool check notebooks

One notebook per capability: run a tool alone on your inputs (or the agent's pasted call) to see whether a problem comes from the tool or from the agent.

- [bifurcation](bifurcation.ipynb): run_bifurcation_analysis, propose_bifurcation_candidates, lhs_bifurcation_scan
- [crnt](crnt.ipynb): crnt_bistability, draw_reaction_network
- [simulation](simulation.ipynb): simulate_model, compare_initial_conditions, plot_phase_plane, custom_plot
- [steady_state](steady_state.ipynb): find_steady_states, jacobian_network
- [stochastic](stochastic.ipynb): stochastic_simulation, propensity_table
- [model_structure](model_structure.ipynb): classify_model, reduce_model
- [fitting](fitting.ipynb): inspect_dataset, estimate_parameters
- [biomodels](biomodels.ipynb): search_biomodels, get_biomodels_info, fetch_biomodels_model, find_biomodels_by_paper
- [retrieval](retrieval.ipynb): search_literature, get_pubmed_article, retrieve_knowledge, read_pdf
- [omnipath](omnipath.ipynb): omnipath_network_check, model_proteins
- [crnt_bistability_stages](crnt_bistability_stages.ipynb): time each crnt4sbml stage
